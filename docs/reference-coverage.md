Compared against the recruiter-supplied PayScope README on 14 October 2026. This is an independent implementation, not a copy of its source. The checklist records behavior and engineering goals; package choices are not assessment requirements.

## Deliberate differences

The app remains a small modular Node/React application with sessions, scrypt and SQLite/Turso. Replacing these with JWT, bcrypt, PostgreSQL, Prisma, Tailwind, Turborepo or a monorepo adds no missing user behavior and would introduce a deployment migration. The viewer never receives salary-band distributions, which is stricter than the reference and documented. Static FX is illustrative, not live. Open HR role selection exists solely for the synthetic assessment; real HR onboarding needs approval/invitations. The app remains single tenant, with no payroll, tax, SSO, password reset or live exchange feeds, matching the reference's stated limits.
