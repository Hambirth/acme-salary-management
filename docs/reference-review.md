# Reference review

Reference supplied by the recruiter: https://github.com/meganathan-tech24/PayScope and https://pay-scope-alpha.vercel.app/login . Reviewed on 14 October 2026.

The README describes React, Express, PostgreSQL/Prisma, JWT authentication, 10,000 employees, employee CRUD, server-side directory filters, CSV export and grouped salary insights. It describes API-enforced HR and viewer permissions, salary redaction, per-currency analytics, tests, architecture notes and an AI prompt log. These are repository claims, not independently verified test results. The live login page loaded and an HR demo sign-in was attempted; backend sign-in remained pending during initial inspection.

Useful ideas for an independent implementation: keep filtering on the server; preserve currency meaning; prevent salary disclosure through the API; make setup and architectural trade-offs clear; include meaningful deterministic tests. Do not copy the reference source or claim its implementation as ours.
